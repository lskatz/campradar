What this page is

Every camp listed here is invented, and so is the organisation offering them. The page exists so Camp Radar has one source that is guaranteed to work — if the dashboard is empty but these appear, the providers changed; if even these are missing, the pipeline is broken. Retire it by setting enabled: false on the example-camps source in config/sources.yaml.
